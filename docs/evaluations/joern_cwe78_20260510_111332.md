## Methodology caveat (critical for interpreting metrics)

Joern source/sink/sanitizer candidates for this sweep were anchored in a **zero-shot (“no-shot”) LLM seed catalog**: vulnerable and patched snippets plus diffs were sent to an LLM with **`SYSTEM_PROMPT_SEED_JOERN`** ([`auditzoo/agents/cwe78_study/prompts.py`](../../auditzoo/agents/cwe78_study/prompts.py)) — **no in-context demonstrations** of correct source/sink lists. That generation step is brittle: the model emits **sink-coloured “sources”** (e.g. `subprocess`, bare `shell`) and other noisy aliases, producing **self-flow** taint traces where Joern quotes the sink as both source and sink. Downstream LLM triage then often yields **`UNCERTAIN`** on otherwise plausible chains, triager overclaim FPs on weak labels, or apparent scan recall gaps — all of which **severely suppressed strict TP**.

This run additionally used the **post-processed merged catalog**:

- Frozen base LLM merge: `results/joern_seed/full_catalog.json` → merged with YAML rules [`auditzoo/agents/cwe78_study/seed_rules/`](../../auditzoo/agents/cwe78_study/seed_rules/) via `splitEvaluations.merge_seed_catalog.py` → **`results/joern_seed/full_catalog_merged.json`**
- **Semantic disjointness blacklist filter:** `splitEvaluations.clean_seed_catalog.py` → **`results/joern_seed/full_catalog_clean.json`** (strip sink tokens from sources; drop non-API sinks like literal `shell`)
- Structural evidence still received a **belt-and-suspenders** tweak in **`auditzoo/agents/cwe78_study/pipeline.py`** (`_structural_evidence_for_finding`) to prefer a **non–self-flow** alternate source when `dedup_sources` allows.

Even after that hygiene pass, catalogue LLM artefacts (generic tokens such as `query`, repo-specific sinks, ambiguous sanitizer names) persist on the inherited seed blob and continue to constrain recall and label quality — see audit FN cause **joern_candidate_missing** below.
